# 臺大電信所丙組介紹網站

給想進丙組（資料科學與智慧網路）的大學部同學看的介紹網站。網站分三頁：認識丙組（教授與研究主題）、修課與準備、學長姐 Q&A。中英文切換，電腦和手機都能看。

整個網站只有一個檔案 `index.html`，不需要資料庫，也不需要後端程式。

## 資料夾

```
index.html        ← 網站本體（要放上伺服器的就是這個檔案）
build.py          ← 把 src/ 組成 index.html
src/
  template.html   ← 版面、樣式、程式、介面文字
  data.json       ← 網站內容（老師、研究主題、課程、Q&A）
docs/
  DESIGN.md       ← 設計規則（字體、顏色、間距）
```

## 怎麼改內容

1. 改 `src/data.json`（內容）或 `src/template.html`（版面、介面文字）。
2. 在專案根目錄執行：

   ```
   python3 build.py
   ```

   只需要 Python 3，不用安裝任何套件。會重新產生 `index.html`。
3. 用瀏覽器直接打開 `index.html` 檢查。
4. 把 `src/` 和 `index.html` 一起 commit。**不要只改 `index.html`**，下次執行 `build.py` 會被覆蓋。

### `src/data.json` 裡有什麼

- `profs`：19 位老師，順序同電信所資網組專任名單。
  - `tags`：卡片上的主要研究。`label` 可以改這一列的標題，例如周俊廷是「研究背景」。
  - `extra`：卡片上的第二列標籤（目前只有葉丙成的「近期研究」）。
  - `summary`：一句白話介紹。
  - `more`：展開後灰底區的「其他研究（參考）」。規則見下方。
  - `src`：展開後的「資料來源」連結。
  - `admit`／`warn`：組別限制。目前只有蘇炫榮老師（本所一般生僅收乙組），`warn: true` 會以橘字顯示，研究主題卡裡他的名字後面也會自動加註。
  - `note`：其他事實（例如周俊廷老師的公司職務）。
- `groups`：「依研究主題找老師」的分組與卡片。`main` 是主要研究，`also` 是相關研究，`lineage` 是研究脈絡；每位老師可以帶 `why`，顯示在名字後面的括號。
- `qa`：13 題學長姐 Q&A（中英）。
- `planned`：115-1 預計開課。
- `prep`：「研究準備」的 5 個研究大類。
- `gice`、`ntuee`：兩份課程地圖。

實驗室名稱、教室、網站連結寫在 `src/template.html` 的 `LABS` 物件；中英對照的介面文字寫在 `T` 物件。

## 放到學校伺服器

網站是純靜態檔案，任何網頁伺服器（Apache、Nginx、IIS，或學校提供的個人網頁空間）都可以放：

- **最簡單：** 把 `index.html` 上傳到伺服器的網站資料夾。
- **用 git 更新：** 在伺服器上 `git clone` 這個 repo，之後每次更新執行 `git pull`，網站目錄指向 repo 根目錄即可。`src/`、`build.py` 放在伺服器上不影響網站。

不需要特別設定。字體會從 Google Fonts 載入 Noto Sans TC；如果學校網路擋外部資源，會自動改用電腦內建的中文字體，版面不受影響。

### 先在 GitHub 上預覽（選用）

repo 的 Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)`，存檔後約一分鐘，會得到一個 `https://<帳號>.github.io/<repo>/` 的網址，可以先給別人看。

## 內容規則（接手一定要看）

1. **Q&A 中文回答要和學長姐原稿逐字一致**，不改寫、不摘要。
2. **不確定的不寫。** 查不到或無法獨立核對的內容一律不放，也不要寫「不確定」「待確認」這類字眼。
3. **網站只寫內容本身**，不寫「這裡怎麼整理」「這張卡是什麼」這類說明文字。避免「不是……而是……」「用……而不是……」這種句型。
4. 不寫老師的剩餘名額或招生承諾，不編造學生或校友的話。
5. **「主要研究」**依老師目前的研究自述、持續投入與角色整理，不能只看論文篇數。
6. **「其他研究（參考）」只寫有持續投入的方向**：
   - 至少兩項彼此獨立的成果（不同學生或不同研究；同一研究的預印本、會議、期刊、學位論文算一項）；
   - 跨至少兩個年度；
   - 老師是指導教授或論文作者（只當共同指導或口試委員不算）。
   - 只指導過一次、只共同指導過一次、只有一篇合作論文、只有研究計畫還沒有成果的，一律不寫，寧可留空。
   - 括號寫年份與證據，例如「（2023、2025 指導論文）」，並在 `src` 放可以點的論文庫或論文連結。指導教授以臺大論文庫的指導教授欄位為準：https://tdr.lib.ntu.edu.tw/
7. 研究主題卡不要用複合標題把老師並列（例如「5G／6G、衛星與邊緣運算」），讀者會以為每位老師都做標題裡的全部方向。
8. 每學年要更新：招生日期在 `src/template.html` 的 `DATES`（Q&A 頁的時程）和 `DL`（首頁倒數）；預計開課在 `src/data.json` 的 `planned`。
9. 版面維持系統字體、白底、大字、簡潔；設計細節見 `docs/DESIGN.md`。

## 資料核對日期

老師研究內容、指導論文與連結的核對日是 2026-10-01。
